## Deployment

### How it works
Every push to `main` triggers `.github/workflows/deploy.yml` which:
1. Runs `git archive` on `app/dist/` (committed artifact — no build step in CI)
2. Uploads as a GitHub Pages artifact
3. Serves at `https://weswuy.github.io/LPCBPool/`

### Build locally (if you edit styles or JS)
```bash
cd app
bun install   # or npm install
bun run build
```
Then commit and push — the workflow deploys whatever is in `app/dist/`.

> **Note:** `app/dist/` is force-added to GitHub even though it's in `.gitignore`. The CI workflow uploads the committed dist, not the working-tree dist. Always rebuild and commit after editing.

### Routing
`base: "/LPCBPool/"` in `vite.config.ts` and `router.tsx` (`hash: false`). All asset paths are root-relative `/assets/...` and work under the subdirectory deployment path.

## Tech Notes

- **Router:** TanStack Router with file-based routes. `tsr generate` auto-creates `routeTree.gen.ts`. The router is configured with `hash: false` for static hosting compatibility.
- **CSS:** Vanilla CSS with custom properties. No Tailwind. All Luna-specific styles in `lpcb-styles.css`.
- **No SSR:** This is a pure client-side SPA. No server-side rendering.
- **Fonts:** IBM Plex Mono and Space Grotesk loaded from Google Fonts.
- **Images:** Hero is WebP (306 KB). Logo/favicon are SVG.
- **Reduced motion:** Respected via `prefers-reduced-motion` media query.
- **Form spam:** Honeypot `website` field included. Real spam protection comes from the form backend (Formspree/Web3Forms handle this).
